# SmartBudget Manager

## Overview

SmartBudget Manager is an Excel workbook that helps users track monthly income and expenses, organize spending by category, and monitor their budget.

## Main Features

- Record income and expenses.
- Categorize expenses.
- Calculate totals and monthly balance automatically.
- Display expense charts.
- Identify budget overspending.

## Requirements

- Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.
- The SmartBudget_Manager.xlsx file.

## Getting Started

1. Open SmartBudget_Manager.xlsx in Microsoft Excel.
2. Open the Transactions worksheet.
3. Enter the date, description, category, and amount of each transaction in the appropriate columns.
4. Open the Dashboard worksheet to review totals, balance, and charts.
5. Check the budget warning to identify overspending.
